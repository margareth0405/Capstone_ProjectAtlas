How to read this result

{% if detection_result.tone == "low" %}

The model found few writing patterns that resemble its AI-generated training examples. This supports a low AI-pattern screening result, but it does not prove who wrote the document.

{% elif detection_result.tone == "high" %}

The model found many writing patterns that resemble its AI-generated training examples. This result needs human review and does not prove that AI wrote the document.

{% else %}

The model found a mixture of human-like and AI-like writing patterns. Treat the result as uncertain and review the document yourself.

{% endif %}
AI-pattern score — {{ detection_result.ai_probability }}%
How strongly the writing matched the model's learned AI-like patterns. It is not an authorship probability.
Human-pattern score — {{ detection_result.human_probability }}%
The complementary score calculated as 100% minus the AI-pattern score. It is not proof of human authorship.
Model certainty score — {{ detection_result.confidence }}%
The larger of the two pattern scores. It describes how strongly the model leaned in one direction, not how accurate the model is.
